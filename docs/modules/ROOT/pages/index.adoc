= Quarkus Docling

include::./includes/attributes.adoc[]

This is a Quarkus extension for the https://github.com/docling-project[Docling project]. Docling simplifies document processing, parsing diverse formats — including advanced PDF understanding — and providing seamless integrations with the gen AI ecosystem.

[link=https://github.com/docling-project/docling-java]
image::docling-java.png[Docling Java,width=300]

Currently, this extension is an implementation of the https://docling-project.github.io/docling-java/current/docling-serve/serve-api[Docling Serve API] provided by https://docling-project.github.io/docling-java[Docling Java] using a https://quarkus.io/guides/rest-client[Quarkus REST client].

The eventual goal is to unify the https://docling-project.github.io/docling/concepts/docling_document[DoclingDocument] format with https://docs.langchain4j.dev/tutorials/rag#document[LangChain4j's `Document` abstraction] so that Docling can be used in a LangChain4j RAG pipeline for ingesting data.

== Compatibility

Each release of this extension targets a single Quarkus https://quarkus.io/blog/tag/lts/[LTS] stream.
New features are developed against the current baseline only and are not backported to earlier streams.

The table below also records which https://github.com/docling-project/docling-java[Docling Java] version each release was built against, so you can find the matching https://docling-project.github.io/docling-java[upstream documentation] for the API you are coding against.

The `0.0.x` releases predate Docling Java; they used a client generated from the Docling Serve OpenAPI specification.
Docling Java `0.1.3` is not linked because the upstream documentation only goes back to `0.1.5`.

If you are still on Quarkus 3.33 LTS, stay on `1.4.4`.
The extension metadata declares `requires-quarkus-core: "[3.40,)"`, so Quarkus tooling will reject an incompatible combination rather than failing at runtime.

The definitive Docling Java version for any release is the `docling-java.version` property in that release's `pom.xml` on Maven Central.

== Docling Features

* 🗂️ Parsing of https://docling-project.github.io/docling/usage/supported_formats/[multiple document formats] incl. PDF, DOCX, XLSX, HTML, images, and more
* 📑 Advanced PDF understanding incl. page layout, reading order, table structure, code, formulas, image classification, and more
* 🧬 Unified, expressive https://docling-project.github.io/docling/concepts/docling_document/[`DoclingDocument`] representation format
* ↪️ Various https://docling-project.github.io/docling/usage/supported_formats/[export formats] and options, including Markdown, HTML, and lossless JSON
* 🔒 Local execution capabilities for sensitive data and air-gapped environments
* 🤖 Plug-and-play https://docling-project.github.io/docling/integrations/[integrations] incl. LangChain, LlamaIndex, Crew AI & Haystack for agentic AI
* 🔍 Extensive OCR support for scanned PDFs and images
* 🥚 Support of several Visual Language Models https://huggingface.co/ds4sd/SmolDocling-256M-preview[SmolDocling]
* 💻 Simple and convenient CLI
